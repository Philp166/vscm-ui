# Изменения

## 0.2.0 — 14.10.2026

Подготовка к передаче в разработку. Внешний вид компонентов и состав сторибука не менялись.

1. Библиотека собирается в npm-пакет: `dist/index.js` (ES), `dist/index.cjs` (CommonJS), типы TypeScript, `style.css` со шрифтом Manrope, `tokens.css` и `tokens.json`. React 18 и 19 — peer-зависимости. Сборка: `npm run build`, архив: `npm run package`.
2. Выпуск версии: при отправке в `main` с новой версией в `package.json` GitHub Actions сам собирает пакет, создаёт тег и выкладывает архив в релиз. Добавлена проверка типов и сборки при каждом изменении.
3. У каждого свойства каждого компонента есть описание. Свойства, заданные прямо в функции, вынесены в именованные интерфейсы и экспортируются (`IconButtonProps`, `FieldProps`, `FunnelProps`, `MirrorCompareProps` и другие).
4. Сторибук: на странице Docs каждого раздела — описание, строка импорта, истории с пояснением и таблица свойств по каждому компоненту, включая разделы с несколькими компонентами. Истории переведены на `args`, поэтому в режиме истории свойства меняются на панели Controls. Добавлена страница «Для разработчиков»: установка, подключение, устройство компонентов, известные ограничения.
5. `Segment`: подложка выбранного варианта перемеряется после загрузки шрифта (раньше при первой загрузке страницы могла быть уже кнопки).

## 0.1.0 — 07.10.2026
