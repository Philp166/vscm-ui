# Для разработчиков

Библиотека собирается в npm-пакет `vscm-ui`: React 18 или 19 и TypeScript, типы в комплекте, графики на чистом SVG без сторонних библиотек, карта на three.js (WebGL). Шрифт Manrope и токены входят в пакет.

## Установка

Пакет выпускается архивом в релизах репозитория на GitHub. Номер версии берите из списка релизов или файла `CHANGELOG.md`:

```bash
npm install https://github.com/Philp166/vscm-ui/releases/download/v0.2.0/vscm-ui-0.2.0.tgz
```

Если у команды есть внутренний npm-реестр, тот же архив публикуется туда командой `npm publish vscm-ui-0.2.0.tgz` и дальше ставится обычным `npm install vscm-ui`.

Нужны `react` и `react-dom` версии 18 или 19: они объявлены как peer-зависимости и в пакет не входят. Пакет `three` для карты ставится автоматически.

## Подключение

Стили подключаются один раз в корне приложения, компоненты импортируются по имени:

```tsx
import 'vscm-ui/style.css';
import { Grid, Card, KpiCard, LineChart } from 'vscm-ui';

export function Page() {
  return (
    <Grid>
      <Card span={12} title="Выпускники">…</Card>
    </Grid>
  );
}
```

Что есть в пакете:

1. `vscm-ui` — все компоненты, их типы и утилиты форматирования `fmt`, `fmtShort`, `NB`.
2. `vscm-ui/style.css` — стили компонентов, токены, шрифт Manrope и базовый сброс стилей.
3. `vscm-ui/tokens.css` — только CSS-переменные токенов, без стилей компонентов.
4. `vscm-ui/tokens.json` — токены в формате DTCG: тот же файл, что загружен в Figma.

`style.css` содержит базовый сброс (`box-sizing`, нулевые отступы) и задаёт шрифт и фон `body`. Он рассчитан на страницы платформы ВСЦМ целиком. Если библиотека встраивается в приложение со своими глобальными стилями, учтите это при подключении.

## Как устроены компоненты

1. **Данные приходят готовыми.** Компоненты не ходят в API: родитель передаёт числа через свойства, компонент сам форматирует их по-русски (разряды неразрывным пробелом, дробь через запятую). Для своих подписей используйте `fmt(value, digits)` и `fmtShort(value)` из пакета.
2. **Выбор хранит родитель.** У `Segment`, `FilterPill`, `SearchSelect`, `ComparePicker` значение задаётся через `value` и меняется через `onChange`. Внутреннее состояние есть только у чисто визуальных переключателей внутри карточек (год на графике, «Числа / Доли», «Раскрыть все»).
3. **Одна карточка — один вопрос.** Почти все блоки сами рисуют карточку `Card` с заголовком. Ширину задаёт сетка: оберните блок в элемент с `grid-column: span N` внутри `Grid` или передайте `span` самой `Card`.
4. **Стиль из токенов.** Цвета, отступы и радиусы берутся из переменных `--color-…`, `--space-…`, `--radius-…` файла `tokens.css`. Прямые значения цветов остались в нескольких местах: карта, тепловая таблица, тёмное верхнее меню и ещё несколько стилей. При смене палитры их нужно проверить отдельно (поиск по `#` в `src/components`).
5. **Свойства описаны в Docs.** На странице каждого раздела внизу есть таблица свойств по каждому компоненту: тип, значение по умолчанию и пояснение. Те же пояснения видны в подсказках редактора кода.

## Известные ограничения

1. **Карта-навигатор на демо-данных.** Значения показателей, список вузов и потоки формируются внутри движка карты (`src/components/map/engine.js`). Передать свои данные через свойства пока нельзя: это следующая доработка карты. Карте нужен WebGL.
2. **Часть блоков заточена под выпускников.** У `HeroNumber`, `NormSummary`, `GroupedTable` и `SparkTable` часть подписей и структура данных встроены в компонент (ВО и СПО, «Трудоустроено», «Округ»). Для других показателей их нужно обобщить. Ограничение указано в описании каждого такого компонента.
3. **Состояния загрузки и пустых данных** есть только у `KpiCard`. Для остальных блоков загрузку и отсутствие данных показывает родитель.
4. **Тёмной темы и отдельных мобильных вариантов в библиотеке пока нет.** Сетка перестраивается по ширине, но верхнее меню `TopNav` и `MirrorCompare` на ширине 375 px выходят за экран.
5. **Шапка главной страницы.** Утверждённый вид шапки главной (переключатель контуров, профиль, уведомления, ассистент) в библиотеку ещё не перенесён. `TopNav` — вариант из UI-кита; при вёрстке шапки сверяйтесь с макетом главной.

## Версии

Версии по semver: исправления повышают последнюю цифру, новые компоненты и свойства — среднюю, несовместимые изменения — первую. Что изменилось в каждой версии, записано в `CHANGELOG.md`.

## Как добавить или изменить компонент

1. Папка `src/components/ИмяКомпонента` с файлами `ИмяКомпонента.tsx`, `ИмяКомпонента.css`, `ИмяКомпонента.stories.tsx`, экспорт в `src/index.ts`.
2. Свойства — именованным интерфейсом, у каждого свойства комментарий `/** … */`: из него собирается таблица свойств и подсказки в редакторе.
3. История задаёт данные через `args`. Если в файле несколько компонентов, история указывает свой: `parameters: { vs: { component: ИмяКомпонента } }`. Тогда у неё появляется таблица свойств и панель Controls.
4. В стилях только переменные из `tokens.css`. Новый цвет или отступ сначала добавляется в `tokens/vscm.tokens.json`, затем `npm run tokens`.
5. Перед выпуском версии: `npm run build` (пакет и типы), `npm run build-storybook`, запись в `CHANGELOG.md`.
