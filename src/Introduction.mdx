# ВСЦМ UI

Библиотека компонентов платформы ВСЦМ. Всё построено на токенах из `tokens/vscm.tokens.json`: цвета, шрифт Manrope, сетка 12 колонок, радиусы, отступы, анимация.

**Правила кита:** один акцент (синий), зелёный и красный только в метке динамики, карточки бенто без обводок и теней, одна карточка — один вопрос, заголовки блоков не меняются от фильтров, первичка открывается только кнопкой.

**Как устроено:** у каждого компонента есть вкладка Docs с описанием свойств и вкладка Design со ссылкой на кадр в Figma.

**Состав по разделам**

1. Основа: карточка и сетка бенто, кнопки, поле, фильтр-капсула, чипы, подсказка, иконки, верхнее меню, полоса уровня раздела.
2. Атомы: метка динамики, сегмент, выбор с поиском.
3. Показатели: герой-цифра, карточка KPI, показатель-доля, сводка с нормой, доля кольцом.
4. Динамика: линейный график, сравнение лет, площадной, столбцы с линией, план и факт, спарклайны в таблице.
5. Структура: горизонтальные и вертикальные столбцы, стековые, полосы 100%, раскрывающиеся столбцы, бублик.
6. Сравнения: выбор сравнения, показатели объектов, выполнение норм, разрыв по специальностям.
7. Таблицы: основная, группировка с подытогами, тепловая.
8. География: карта-навигатор (WebGL) со всеми режимами.
9. Потоки и схемы: воронка пути, куда уезжают, баланс региона.
10. Рейтинги: движение мест, по нескольким показателям, место объекта.
11. Объекты: паспорт организации, карточка вуза, карточка региона.

Все данные в историях демонстрационные.
