# ВСЦМ UI

Библиотека компонентов платформы ВСЦМ. Всё построено на токенах из `tokens/vscm.tokens.json`: цвета, шрифт Manrope, сетка 12 колонок, радиусы, отступы, анимация.

**Правила кита:** один акцент (синий), зелёный и красный только в метке динамики, карточки бенто без обводок и теней, одна карточка — один вопрос, заголовки блоков не меняются от фильтров, первичка открывается только кнопкой.

**Как устроено:** у каждого компонента есть вкладка Docs с описанием свойств и вкладка Design со ссылкой на кадр в Figma.

Состав первой волны: карточка, метка динамики, сегмент, выбор с поиском, карточка KPI, показатель-доля, линейный график, горизонтальные столбцы, рейтинг с движением мест, основная таблица.
