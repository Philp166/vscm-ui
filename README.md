# ВСЦМ UI: токены, компоненты, Storybook

Библиотека компонентов платформы ВСЦМ: React 18/19 и TypeScript, графики на чистом SVG без сторонних библиотек, карта на three.js (WebGL). Источник правды по стилю — `tokens/vscm.tokens.json`.

Сторибук с описанием каждого компонента и его свойств: <https://main--6abf9a18a03505b6ff99ba73.chromatic.com/>. Начните со страницы «Для разработчиков».

## Установка

Пакет выпускается архивом в [релизах](https://github.com/Philp166/vscm-ui/releases):

```bash
npm install https://github.com/Philp166/vscm-ui/releases/download/v0.2.0/vscm-ui-0.2.0.tgz
```

```tsx
import 'vscm-ui/style.css';              // один раз в корне приложения
import { Grid, KpiCard } from 'vscm-ui';
```

| Путь | Что это |
| --- | --- |
| `vscm-ui` | Компоненты, их типы, утилиты `fmt`, `fmtShort`, `NB` |
| `vscm-ui/style.css` | Стили компонентов, токены, шрифт Manrope, базовый сброс стилей |
| `vscm-ui/tokens.css` | Только CSS-переменные токенов |
| `vscm-ui/tokens.json` | Токены в формате DTCG (тот же файл, что в Figma) |

`react` и `react-dom` (18 или 19) ставит приложение. Известные ограничения и правила работы с компонентами — на странице «Для разработчиков» в сторибуке и в `src/ForDevelopers.mdx`. История версий — в `CHANGELOG.md`.

## Что внутри репозитория

| Папка | Что это |
| --- | --- |
| `tokens/` | Токены ВСЦМ (тот же файл, что грузится в Figma) |
| `src/components/` | Компоненты: у каждого код, стили и истории для сторибука |
| `src/styles/tokens.css` | CSS-переменные, собранные из токенов командой `npm run tokens` |
| `.storybook/` | Настройки сторибука и общая страница Docs с таблицами свойств |
| `vite.lib.config.ts`, `tsconfig.build.json` | Сборка пакета |
| `.github/workflows/` | Публикация сторибука в Chromatic, проверка сборки, выпуск версии по тегу |

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run storybook` | Сторибук на <http://localhost:6006> |
| `npm run build` | Сборка пакета в `dist/` |
| `npm run package` | Сборка и архив `vscm-ui-<версия>.tgz` |
| `npm run typecheck` | Проверка типов |
| `npm run tokens` | Пересборка `tokens.css` из `tokens/vscm.tokens.json` |

## Как добавить или изменить компонент

1. Папка `src/components/ИмяКомпонента` с файлами `ИмяКомпонента.tsx`, `ИмяКомпонента.css`, `ИмяКомпонента.stories.tsx`, экспорт в `src/index.ts`.
2. Свойства — именованным интерфейсом с комментарием `/** … */` у каждого свойства: из них собирается таблица свойств в сторибуке и подсказки в редакторе.
3. История задаёт данные через `args`. Если в файле несколько компонентов, история указывает свой: `parameters: { vs: { component: ИмяКомпонента } }`.
4. В стилях только переменные из `tokens.css`. Правка стиля начинается в `tokens/vscm.tokens.json`, затем `npm run tokens`; тот же JSON загружается в Figma через Tokens Studio.

## Выпуск версии

1. Поднять `version` в `package.json` и записать изменения в `CHANGELOG.md`.
2. Отправить изменения в `main`:

```bash
git commit -am "Версия 0.2.1"
git push origin main
```

GitHub Actions увидит, что релиза с этой версией ещё нет, соберёт пакет, создаст тег `v0.2.1` и выложит архив в релиз. Если версия в `package.json` не менялась, новый релиз не создаётся. Сторибук публикуется в Chromatic автоматически при каждом изменении в `main`; у карты снимки «было / стало» отключены, потому что WebGL рисует по-разному от запуска к запуску.

## Связь с Figma

У компонентов во вкладке Design ссылка на кадр в Figma задаётся параметром `design.url` в файле `*.stories.tsx`. В обратную сторону: плагин Storybook Connect в Figma, вход через Chromatic, ссылка на историю у кадра компонента.
